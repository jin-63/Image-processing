## ** 이미지프로세싱2 **

### 스레시홀딩(Thresholding, 청년프로세스)
경계점 기준으로 이미지 속을 이루는 모양과 경계선을 이해하기 쉽게 이해하기 위한 바이너리 이미지를 사용하기

- retVal , result = cv2.threshold(sourceImage, thresholdVal, maxVal, thresholdType)
- retVal -> 스레시홀더에 사용되는 경계값을 돌려드립니다
- sourceImage -> 스레시홀딩을 할 이미지
- threshVal -> 스레시홀더에 사용되는 경계값
- maxVal -> 경계값을 초과할 때 매기는 값
- ThresholdType -> 스레시 홀딩 타입

### 이미지 연산(OpenCV와 NumPy연산의 구별)
두 가지 이미지를 서로 빼거나 더하는것으로 새로운 결과 이미지를 생성합니다(서로 곱하거나 나누지 않음)

** OpenCV 사용 **
- 클리핑(clipping): OpenCV는 광대역 범위 값이 255를 초과하면 값을 클리핑(clipping)해서 255를 유지합니다.
- cv2.add(np.uint8( [ 200 ] ), np.uint8( [ 100 ] )) 는 200+100= 300이지만 255가 최대
- cv2.subtract(np.uint8( [ 50 ] ), np.uint8( [ 100 ] )) 은 50-100= -50이지만 0이 최소
** Numpy 사용 **
- 랩어라운드(wrap around): NumPy는 225가 많은 경우 공유 값을 0부터 다시 더 많은 범위(wrap around) 때문에 255을 공유 거리에서 1을 더 뺌(0부터 시작)
- np.uint8( [ 200 ] ) + np.uint8( [ 100 ] ) 은 200+100= 300이지만 300-256=44가 최대
- np.uint8( [ 50 ] ) - np.uint8( [ 100 ] )은 50-100= -50이지만 256-50=206이 최소

### 비트와이즈 배열(bitwise-option)
두 이미지를 혼합할 때 특정 지역만 또는 특정 범위만 제외하는 등 선택적인 공유에 사용
두 이미지는 같은 모양을 가지고 있어야 합니다.
- AND ->찾는 두 쌍이 모두 0보다 크면 ture로 돌아와요
- 또는 -> 비교하는 두 개의 낮은 평행 배열이 0보다 크거나 둘 사이 0보다 크면 true로 돌아갑니다
- XOR -> 비교하는 두 개의 확장된 확장형 배열이 0보다 넓은 두 개의 확장형과 동시에 0보다 유연할 때 true를 반환합니다.
- NOT-> 하나의 이미지가 0이면 true이고, 0이 아니면 false를 반환합니다(바이너리 이미지 반전 효과)

### 이미지 마스킹(Image Masking)
하나의 이미지에서 원하는 영역만 분리하는 작업
- 마스크(mask)는 바이너리 이미지로, 특정 이미지에서 0이 아닌 슬라이더만 올라갈 수 있도록 함

### HSV 컬러 범위로 스레시홀딩 후 이미지 마스킹하기
RGB보다 HSV컬러채널이 더 색범위를 구하기 쉬움
OpenCV는 uint8 자료형으로 0부터 255 값으로 색상과 채도, 명도 값을 표현
- Hue(색상)은 360°/2=180°로 [0,179] 사이 값으로 표현하고 180-255까지의 값은 179로 표현
- Saturation(채도)는 0-100% 값을 [0,255]범위로 표현
- Value(명도)는 0-100% 값을 [0,255]범위로 표현

## 히스토그램
히스토그램은 이미지의 픽셀 값 분포를 그래프로 표현
```cv2.calcHist(image, chennels, mask, histSize, ranges)```

### RGB 컬러 이미지 2D, 3D 히스토크램 구하기
- RGB 이미지의 3개의 채널을 2차원으로 표현하면 2채널씩 비교할 수 있어서 총 3개의 2D히스토그램으로 나타낼 수 있다
- 다차원 히스토그램을 그릴 때 빈(bin)갯수를 256이 아닌 8~64개 정도로 줄여서 표현
  - 2D히스토그램에 256개의 빈(bin)을 사용하면 256x256=65,536개의 픽셀을 따로 세어 표현하기 때문에 연산 속도가 느리다.

### 히스토크램을 사용해 이미지의 화질을 개선하거나 이미지를 분류하는 방법
### 1. 히스토그램 정규화
기준이 서로 다른 데이터 범위를 0-1사이로 맞춰 데이터 분포를 특정구간으로 바꾸는 기법
- 이미지에서 정규화가 필요한 경우
  - 픽셀의 분포가 한곳에 집중되어 몰려 있는 화질을 개선하기 위해 노멀라이즈 적용
  - 이미지 간의 연산 시 서로 조건이 다른 경우 같은 조건으로 만들기 위해 노멀라이즈 적용
- 픽셀의 분포를 늘려서(stretching) 이미지의 명암(contrast,색채대비)을 개선
  - 한 곳에 집중된 영역과 멀리 떨어진 값이 있을 경우에는 노말라이즈는 효과가 없음
  
```cv2.normerlize(srcimage, dstimage, alpha, beta, norm_type, mask)```

Parameters:
- srcImage - 사용할 이미지 데이터
- dstImage - srcImage와 같은 크기의 노멀라이즈 이후 이미지 데이터
- alpha - 구간 노멀라이즈 범위의 아래 경계값
- beta - 구간 노멀라이즈 범위의 윗 경계값
- normType - 노말라이즈 알고리즘 옵션
  - NORM_MINMAX - alpha와 beta 구간으로 노멀라이즈
  - NORM_INF - 최대값으로 나누기
  - NORM_L1 - 전체 합으로 나누기, alpha가 노멀라이즈 전체 합
  - NORM_L2 - 단위 벡터로 노멀라이즈

### 2. 히스토그램 평탄화
이퀄라이즈/평탄화는 각각의 값이 전체 분포에 차지하는 비중에 따라 분포를 재분배해서 명암 대비를 개선하는 데 효과적이다.
- 픽셀의 분포를 늘려서(stretching) 이미지의 **명암(contrast,색채대비)**을 개선
- 보통 그레이스케일 이미지에 적용하지만 HSV, YUV등 컬러이미지에도 적용가능
- 전경과 배경이 둘 다 밝거나 어두울 때 도움이 됨
- 사진에서는 보통 비현실적인 효과가 나타나지만 의학이나 위성사진 등에 적용하면 명암개선 효과가 있음
- RGB의 경우 3개의 채널을 다 적용해야 하지만 HSV는 Value(명도/밝기)채널만 연산해 적용하면 쉬움


### 3. 히스토그램 CLAHE
이미지 전체에 이퀄라이즈를 적용했을 때 너무 밝은 부분이 날아가는 현상을 막기 위해 이미지를 일정한 영역으로 나누어서 적용
- 잡영/노이즈가 증폭되는 것을 막기 위해 히스토그램 빈(bin)이 제한 값을 넘으면 다른 빈(bin)으로 배분 후 이퀄라이즈 적용

### 4. 히스토그램 유사도 비교
두 이미지의 픽셀 값의 분포를 나타내는 히스토그램을 비교 후 픽셀 값의 분포가 서로 비슷하다면 유사한 이미지일 확률이 높음
```cv2.compareHist(hist1, hist2, method)``` 

parameters:

- hist1, hist2: 비교할 두 개의 히스토그램, 크기와 차원이 같아야 함
- method: 비교 알고리즘
  - CV_COMP_CORREL: Correlation/상관관계 (1: 완전 일치, -1: 완전 불일치, 0: 무관계)
  - CV_COMP_CHISQR: Chi-Square/카이제곱 (0: 완전 일치, 무한대: 완전 불일치)
  - CV_COMP_INTERSECT: Intersection/교차 (1: 완전 일치, 0: 완전 불일치(- 1로 정규화한 경우))
  - CV_COMP_BHATTACHARYYA: Bhattacharyya distance/바타차야 거리 (0: 완전일치, 1: 최대 불일치)
